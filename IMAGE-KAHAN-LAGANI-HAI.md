### Featured Images (Upar Wale - Hero):
- **Size:** 1400 x 900 pixels
- **Kahan:** Title k baad, content se pehle
- **Kitna Bada:** Full width, bahut prominent
- **Kitne:** Har blog mein 1 (total 10)

- **Size:** 1200 x 800 pixels
- **Kahan:** Content k baad, neeche ribbon mein
- **Display:** Horizontal scroll (left-right)
- **Kitne:** Sirf 3 blogs mein (total 5 images)

## 💡 Important Points

1. **Automatic Display:** Images automatically sahi jagah display honge
2. **No Code Needed:** Database mein already URLs set hain
3. **Just Add Files:** Bas files folder mein daal do
4. **Exact Names:** Filenames bilkul wahi hone chahiye
5. **Hard Refresh:** Images add karne k baad Ctrl+Shift+R daba do
